# AlphaFold-predicted protein structures

This repository contains AlphaFold-predicted protein structures associated with the manuscript:

"Benralizumab-IL-5Ra", "Mepolizumab-IL-5", "Reslizumab-IL-5".

## Files

* `Benralizumab-IL-5Ra.pdb` — AlphaFold-predicted structure of IL-5Rα (A chain), Benralizumab Fab HC (B chain) and Benralizumab Fab LC (C chain).
* `Mepolizumab.pdb` — AlphaFold-predicted structure of IL-5 (A and B chains), Mepolizumab Fab HC (C chain) and Mepolizumab Fab LC (D chain).
* `Reslizumab.pdb` — AlphaFold-predicted structure of IL-5 (A and B chains), Reslizumab Fab HC (C chain) and Reslizumab Fab LC (D chain).

## Structure prediction

Protein structures were predicted using AlphaFold3 (https://alphafoldserver.com/about?golgi=true).


## Notes

The PDB files contain the predicted structures used in the analyses described in the associated manuscript.
